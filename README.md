# HOLA 家具庫存與數位報價系統 (Furniture Quick Quote System)

## 專案簡介
這是一個為前線家具銷售業務量身打造的「輕量化數位武裝系統」。

當傳統 POS 機還在吐出那種沒有靈魂、缺乏圖片，且佈滿枯燥免責聲明的 A4 紙本報價單時，本系統能讓業務人員在 10 秒內，透過行動裝置直接產出極具質感、自動加總金額的電子報價圖卡。無須龐大後端伺服器，單靠 Google Sheets 作為無頭資料庫 (Headless CMS) 與前端渲染技術，即可完成對實體零售流程的降維打擊。

## 核心火力 (Features)
- **雲端算力外包 (Google Sheets Integration)**：直接綁定 Google 試算表發布的 CSV，將最繁重的資料庫維護與跨表比對邏輯，全數外包給造價百億的 Google 伺服器去扛。
- **一鍵數位轉生 (html2canvas Rendering)**：內建截圖黑魔法，一鍵將排版精美的 HTML 報價單轉換成高畫質圖片，無縫傳送至顧客的 LINE，徹底終結手寫廢紙的時代。
- **光學條碼絞肉機 (Optical Barcode Parsing)**：直接劫持手機原生相機，結合三段式正規表達式 (RegEx) 暴力過濾，無論商品標籤網址被塞入多少亂碼，照樣精準挖出 9 碼 SKU。
- **商品生死判官 (Dynamic Status Tagging)**：即時連線讀取商品狀態，正常品亮綠燈，不續訂 (D) 商品直接貼上絕版死亡標籤，從視覺上對猶豫不決的顧客進行強迫性逼單。

## 部署與使用方式 (Deployment)
如果你是其他單位的業務想把這套系統偷去用：
1. 將本專案 Fork 至你的 GitHub。
2. 進入 `index.html`，將 `GOOGLE_SHEET_CSV_URL` 替換為你們自己單位的試算表直連網址。
3. 確保你的試算表內擁有對應的欄位名稱（如：SKU、商品名稱、楊梅庫存、一般售價、促銷售價、商品狀態等）。
4. 在 GitHub Repo 設定中開啟 **GitHub Pages**。
5. 用手機瀏覽器打開網頁，並選擇「加入主畫面」，將其偽裝成一個高質感的原生 APP。

## 系統限制與警告
- 本系統高度依賴 Google Sheets 的 CSV 發布功能，若總公司哪天封鎖了雲端權限，本系統將瞬間淪為一塊沒有用處的數位磚頭。
- 產出的報價圖卡過於精美，極有可能導致顧客以為你是什麼高階設計師，請自行拿捏服務尺度。
